# Experiments

Directorio para experimentos reproducibles relacionados con la Hipotesis de Riemann.

## Reglas

1. Todo experimento debe indicar si depende o no de RH.
2. Todo resultado numerico debe registrar precision, parametros y version de librerias.
3. Ningun experimento numerico constituye una prueba general.
4. Los scripts deben poder ejecutarse desde cero.

## Experimentos previstos

- Evaluacion numerica de `Xi(t)`.
- Evaluacion del nucleo de Riemann `Phi(u)`.
- Determinantes de positividad total.
- Aproximantes finitos de `Xi`.
- Polinomios estables derivados de discretizaciones.
- Comparacion con ceros conocidos.
