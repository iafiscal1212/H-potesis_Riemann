# Results - Gaussian quadrature approximants for Xi

## Experiment

Script:

```text
experiments/gaussian_quadrature_xi_from_phi.py
```

The construction uses the even measure

```math
w(x)=\Phi(|x|)
```

on the real line.

For even functions,

```math
\int_{-\infty}^{\infty}\Phi(|x|)\cos(zx)dx
=2\int_0^\infty\Phi(u)\cos(zu)du.
```

Thus Gaussian quadrature for `w(x)` gives approximants

```math
\Xi_N(z)=\frac12\sum_{j=1}^{N}w_j\cos(zx_j),
```

where `x_j` and `w_j` are quadrature nodes and weights obtained from the Jacobi matrix generated by moments of `Phi`.

## Non-circularity

This construction uses:

- the Phi kernel;
- moment integrals;
- Jacobi matrices;
- Gaussian quadrature.

It does not use the nontrivial zeros of zeta as input.

## Numerical behavior

For moderate real values of `z`, the quadrature approximants converge well to the direct integral evaluation of `Xi(z)`.

Representative behavior:

```text
z = 0:
  Xi(z) ~= 0.0621400972735
  quadrature values agree essentially exactly for n >= 4.

z = 10:
  Xi(z) ~= 0.0158821140009
  n=4  error ~= 2.8e-4
  n=6  error ~= 4.8e-7
  n=8  error ~= 2.4e-10
  n=10 error ~= 1.8e-13

z = 14.134725:
  Xi(z) is close to zero, near the first nontrivial zero ordinate.
  quadrature approximants reproduce the small value and sign behavior increasingly well.
```

## Interpretation

This is an important constructive link:

```math
\Phi \rightarrow moments \rightarrow Jacobi matrix \rightarrow Gaussian quadrature \rightarrow \Xi_N(z).
```

The resulting approximants are non-circular and naturally attached to `Xi`.

## Key new question

Do the functions

```math
\Xi_N(z)=\frac12\sum_{j=1}^{N}w_j\cos(zx_j)
```

have only real zeros?

If yes for all `N`, and if `Xi_N -> Xi` locally uniformly, this would be a serious Laguerre-Polya route.

## Warning

Finite sums of cosines with positive weights and real nodes do not automatically have only real zeros.

The next experiment must scan zeros of `Xi_N` in the complex plane or transform the cosine sum into an exponential polynomial and test stability.
