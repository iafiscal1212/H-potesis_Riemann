# Via 3 - Herglotz route

## Goal

Study whether the logarithmic derivative of the Riemann Xi function can be placed inside a Pick or Herglotz framework.

## Core object

```math
M(z)=-Xi'(z)/Xi(z)
```

For entire real functions whose zeros are all real, logarithmic derivatives have strong half-plane mapping properties.

## Desired implication

If a positive integral representation for `M(z)` can be obtained without assuming RH, then the real-zero property of `Xi` may follow.

## Warning

This route is very close to RH itself. Any positivity representation must be checked for circularity.

## First tasks

1. Write the product representation of an entire function with real zeros.
2. Compute its logarithmic derivative.
3. Identify the half-plane sign property.
4. Compare with `Xi`.
5. Search for a non-circular positive measure representation.
