# Notes

Directorio para notas de lectura, derivaciones, borradores y auditorias.

## Convenciones

- Usar nombres con prefijo numerico cuando haya una secuencia logica.
- Marcar claramente si una afirmacion es demostrada, conjetural o experimental.
- Incluir referencias cuando se consulte una fuente externa.
- Registrar dudas abiertas al final de cada nota.
